## 准备

1. Windows 测试机安装/运行面试助手，另一台设备加入同一场真实腾讯会议。
2. 在设置中填写百炼 API 密钥、对应地域的 WebSocket 地址；测试识别连接。需要 AI 生成时再填写 DeepSeek 密钥。
3. 本机使用耳机，远端设备在独立位置通过腾讯会议麦克风说话。
4. 先使用“音频检测”，确认系统声道 RMS 随远端语音变化；结束检测后使用“开始会话”验证真实转录。
