## 本机环境问题及处理

- PowerShell 的全局 npm 包装脚本失效，开发过程中使用 Node 安装目录内的 npm CLI 完成依赖安装。
- Electron 官方源的大文件传输超时，通过分段下载发行镜像、与锁定官方 npm 包内的 SHA256 比对后安装运行时。
- 托管终端限制了 Electron 自身沙箱读取运行时目录；桌面检查在允许本地应用正常运行的执行环境中完成，应用保持 `contextIsolation` 和 Chromium sandbox 开启。
